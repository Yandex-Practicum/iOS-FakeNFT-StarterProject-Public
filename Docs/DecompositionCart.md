# Декомпозиция эпика Корзина


## Модуль 1:

#### Верстка экрана корзина
- Создание таблицы для отображения списка NFT (est: 1 час; fact: 1,5 часов)
- Верстка ячейки с изображением, названием, рейтингом, ценой и кнопкой удаления (est: 4 часа, fact: 2 часа).
- Верстка нижней панели с количеством NFT, общей суммой и кнопкой оплаты (est: 2.5 часа, fact: 1 час).
- Верстка картинки NFT, кнопки (Удалить / Вернуться), AutoLayout + модальное отображение (est: 2 часа; fact: 1 час)

#### Логика корзины
- Получение списка NFT (est: 3 часа, fact: 2 часа).
- Логика удаления NFT (показ подтверждения, обновление данных) (est: 2.5 часа, fact: 1 час).
- Пересчет общего количества и суммы при изменениях (est: 1.5 часа, fact: 0,5 часов).
- Реализация сортировки NFT по цене/рейтингу/названию (est: 2 часа, fact: 1 час).


## Модуль 2:

- Логика выбора и выделения валюты (est: 1 час, fact: х часов).

#### Обработка платежей
